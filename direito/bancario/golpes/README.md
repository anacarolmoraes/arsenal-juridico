# Bundle de Competência — Golpes Bancários

Bundle de **matéria** do tema *golpes bancários por engenharia social* (falsa central, golpe do PIX), construído por **ingestão de cadeias de litígio** (schema v0.4, ritual 7.5): cada processo entra como uma unidade — inicial, sentença, recursos e acórdãos — e o agente deriva a trajetória, os acórdãos citáveis e, principalmente, os **contra-ataques** (como cada fundamento desfavorável foi derrotado, com trechos literais e página).

## Instruções para o agente

1. Navegue por progressive disclosure a partir do [index.md](index.md).
2. Ao enfrentar uma decisão desfavorável num caso do tema, consulte **primeiro** [contra-ataques/](contra-ataques/index.md) — busca por transição (`sentenca->tj`, `tj->stj`) e natureza (`argumentativo`, `probatorio`, `processual`).
3. Cite fontes pelo `resource`/número do processo; trechos literais só com localização (página do raw/). Nunca cite dados pessoais de terceiros (regra 6.5 do schema).
4. Consumidores não modificam o bundle. Petições de terceiros em `raw/` não são redistribuíveis.
